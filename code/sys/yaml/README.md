# YAML

Tools for working with [YAML](https://yaml.org/spec/1.2.2/) parsing, serialization, and
schema-driven data structures.

## Usage

For basic YAML parsing and manipulation, import the core helpers from:

```ts
import { Yaml } from 'jsr:@sys/yaml'; //  ← primary entry
import { Yaml } from 'jsr:@sys/yaml/core'; //  ← same (core layer)
```
