# Plan: @sys/cell root-help DSL preflight

Status: queued for a separate implementation run.

Implementation-run name: `cell-dsl-preflight-help`

Proposed commit:

```text
docs(cell/help): surface DSL as preflight in root help
```

## Principle

Do not fold `@sys/cell` symmetry into the `@sys/tmpl` root-help commit.

`@sys/cell` has a different command model: `init`, `dsl`, and `start` operate a Cell boundary and its owner/service rules; `@sys/tmpl` maps scaffold prompts to template names and required slots. A Cell pass should reuse the preflight-discovery idea, not copy the templater prompt-mapping table.

## Goal

Make the root `@sys/cell --help` surface treat `dsl` as the first stop before changing a Cell folder.

The help should tell agents to consult the DSL before editing `cell.yaml`, registering services, wiring owner configs, or starting runtime flows.

## Likely files

- `code/sys/cell/src/m.help/yaml/root.yaml`
- `code/sys/cell/src/m.help/-bundle/-bundle.json` if regenerated by the Cell help bundle task
- `code/sys/cell/src/m.cli/-test/*` only if existing root-help tests assert exact text/order

## Candidate changes

1. Keep the root summary Cell-focused, but add a short directive line:
   - `Run dsl first before changing Cell config, owners, services, or routes.`
2. Make the `dsl` command description imperative:
   - `run first — maps Cell acts, owners, rules, and chapters`
3. Consider moving the `dsl` usage line directly after `--help`, before write/start examples.
4. Do not add a templater-style prompt-mapping table unless a Cell-native mapping can stay short, exact, and owner-safe.

## Acceptance criteria

- Root help makes `dsl` visually discoverable before mutation-oriented commands.
- Copy remains accurate to Cell semantics: acts, owners, services, routes, runtime.
- No changes to Cell CLI parsing, command behavior, exit codes, or DSL YAML chapter structure.
- Existing Cell root-help tests pass, or are updated only for the intentional text/order change.

## Non-goals

- No `@sys/tmpl` edits.
- No templater prompt/template mapping copied into Cell.
- No new flags or agent-specific help mode.
- No owner-config implementation changes.
