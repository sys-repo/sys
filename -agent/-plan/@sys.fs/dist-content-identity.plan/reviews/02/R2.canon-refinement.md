## Decision

The human's thirteen-item punch list has merit, with one formatter-based rejection and bounded
refinements below. Applied surgical changes only. This is an implementer quality pass, not an
independent review, exhaustive canon certification, or landing clearance.

   preserves the entry type; a compact returned tuple inside a short mapping block is stable.
3. **Accept.** Named FS verification results and Vite changed-byte/stale-pin observations. Preserved
   assertion values, path diagnostics, call order and the independently held expectations.
4. **Accept.** Bound DataPipeline cases and Pull invalid pins before their simple loop headers.
5. **Accept.** Used `Str.dedent` only for duplicate-member JSON fixtures. Literal duplicate and
   escaped keys remain; separate byte-exact preimages, fixed digests and BOM controls are untouched.
6. **Accept with replacement proof.** Removed namespace import/export-set enumeration. Named public
   `useDist` is asserted identical to its production implementation, and ordinary hook tests now use
   that public barrel. The explicit named-only barrel remains unchanged. Symbol identity does not
   itself prove absence of every other export; do not describe it as an export-set proof. The
   internal delayed-loader tests retain their separate implementation import.
7. **Accept.** Moved `Observation`, transport-local observation types and Vite response aliases
   before runtime declarations. Also moved the existing local `FinalEvidenceResult` to the same
   position in the touched materialization runner. No runtime ordering was changed by these erased
   declarations.
8. **Accept, contained.** Moved `ManifestFetchFailure` and `ManifestResponse` to materialization's
   local `t.internal.ts`, composed through its local `common.ts` type namespace. No package-public
   type export was added. This is not a migration of every other internal type in Server.
9. **Accept.** Used method shorthand for the two block-bodied object callbacks. Neither uses lexical
   `this`; callback arguments, laziness and bodies remain unchanged.
10. **Accept.** Multiline JSDoc marks public `fromDist` and `materialize`; injection seams remain
    compact.
11. **Accept.** Route fixtures use canonical `Json` via the common library lane; compact fixtures
    use zero indentation. Pretty JSON now receives the canonical trailing newline, and the existing

12. **Accept, without stronger admission.** Guard inputs are `unknown`; structural narrowing
    replaces premature `Pkg`/`DistPkg` assertions. Native string/array guards became `Is` calls. The
    existing encoder implementation accepts unknown internally and is shared directly with the
    guard, avoiding a false parts cast or duplicate/unbounded validation pass. The public Content
    namespace and typed encode contract are unchanged. A characterization test passed before and

    generic Proxy/accessor firewall, digest recomputation or new FS metadata requirement is claimed.
13. **Accept.** Removed outer `readonly` from the three `FromDistOptions` fields. Kept acceptance of
    `DeepReadonly<DistContent>` inventory inputs and all returned-content guarantees. The shared
    base options contract was not rewritten.
