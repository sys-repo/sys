# Dist content identity — supporting records

The [primary plan](../dist-content-identity.plan.md) remains the governing contract and sole landing
ledger. This folder organizes supporting evidence; it adds no work, review gate or execution authority.

- [Adjacent findings](./adjacent-findings.md): separately scoped observations, not automatic work.
- [Review records](./reviews/README.md): retained prompts, reports, adjudications and execution notes
  for rounds [01](./reviews/01/), [02](./reviews/02/) and [03](./reviews/03/).
- Handoffs: [Cloudflare tests](./handoffs/cloudflare-test.handoff.md),
  [R2 sample](./handoffs/r2-sample.handoff.md), [Vite tests](./handoffs/vite-test.handoff.md), and
  [object-method candidates](./handoffs/object-methods.handoff.md).

Records retain their original phase-specific claims and instructions. Consult the primary plan for
current decisions; old dispatch instructions, findings and proof gaps do not revive work or establish
current readiness. Historical command, report-output and evidence paths remain as recorded, including
references to removed temporary files. They are not necessarily runnable or available today.

Location mapping: the former `dist-content-identity.plan.reviews/` tree is now `reviews/`;
`dist-content-identity.adjacent-findings.md` is now `adjacent-findings.md`; the four former
`dist-content-identity.*.handoff.md` files are now in `handoffs/` without that repeated prefix.
Only navigation references are repaired during this move; historical evidence is not rewritten.
